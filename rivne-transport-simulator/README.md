# Гра-симулятор транспорту Рівного 3D

Вебгра v1.2. Керування тролейбусом або маршруткою, демонстраційні рейси, пасажири та оплата, світлофори, пішохідні переходи, штрафи, зміна камер. Гра не є точною копією міста та має стилізовану 3D-графіку. Для роботи 3D-бібліотеки потрібен інтернет.

**Грати:** відкрийте `index.html` або сторінку GitHub Pages цієї папки. Для телефону краще горизонтальний екран.

**Авторство фотографій:** фотографії транспорту й міста надано користувачем для цього проєкту. Дані карт © OpenStreetMap contributors.
